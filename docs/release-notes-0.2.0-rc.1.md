本候选纳入已通过真实验收的 ligand-first 小批量工作流：母体检索、Cys 配对核验、方案冻结、官方枚举、完整批次化学准入、最多六个准入候选直接 CovDock-LO、结构评价及 Results 交付。更多候选的 VS→LO 路由保持已有策略，本次真实验收不覆盖其目标规模性能。
