姿态检查通过不建立实验活性、反应动力学或选择性。AF3 与 MD 未在本轮执行。以上为固定候选版的历史真实验收，不能替代后续源码整合版本的回归与部署冒烟。

## 可重复执行的基础回归

在仓库根目录、已安装科研依赖及 pytest 的环境中执行：

```sh
python -m pytest -c pytest-ligand-release.ini
```

该入口覆盖母体索引分页与表外处理、Cys 配对环境和距离边界、结构身份绑定、报告防篡改及候选分流。使用本地测试数据，不启动远端计算。它不替代三类真实会话验收、官方枚举集成和部署冒烟。
